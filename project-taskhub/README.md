# Финальный проект по C\# - Console App “TaskHub”

**🎯 Цель проекта**

Разработать консольное приложение для управления задачами: создание, редактирование, поиск, выполнение, сохранение в файл и асинхронная работа со статистикой.

---

## 📌 TaskHub - менеджер задач

Приложение должно работать через консольное меню.

### ⚙️ Функциональные требования

1. Создание задачи

    Пользователь может создать задачу с:

    * названием
    * описанием
    * приоритетом (Low / Medium / High)
    * дедлайном
    * статусом (New / InProgress / Done)

2. Просмотр задач

    Отображение:

    * всех задач
    * выполненных
    * невыполненных
    * задач с высоким приоритетом

3. Редактирование задачи

    Возможность изменить:

    * название
    * описание
    * приоритет
    * статус

4. Удаление задачи

5. Поиск задач

    Поиск должен работать:

    * по названию
    * по статусу
    * по приоритету

6. Статистика

    Приложение должно показывать:

    * общее количество задач
    * количество выполненных
    * количество просроченных
    * статистику по приоритетам

7. Сохранение задач в файл

8. Загрузка задач из файла

9. Асинхронная работа с файлами

    Использовать `async`/`await` для:

    * сохранения
    * загрузки данных

10. Фоновая проверка задач

    Отдельный поток или `Task`, который:

    * раз в несколько секунд проверяет дедлайны
    * выводит уведомление о просроченных задачах

---

### 🛠 Что обязательно использовать

* ✅ ООП и классы
* ✅ Коллекции (List, Dictionary)
* ✅ Generic
* ✅ Делегаты
* ✅ Обработка исключений
* ✅ IDisposable
* ✅ static классы/методы
* ✅ async/await
* ✅ Многопоточность
